# Баг-репорт задания 2.2

## [Создание задачи] Пропуск необязательного поля во время создания задачи приводит к тому, что задча не создаётся.

### Приоритет: high

### Шаги воспроизведения:
1. Сформировать случайное имя задачи.
2. Перейти на страницу https://avito-tech-internship-psi.vercel.app/
3. Открыть окно создания задачи.
4. Заполнить все обязательные поля, выбрать 1-ый вариант во всех активных выпадающих списках, пропустить необязательное поле, создать задачу.  
5. Найти созданную задачу по имени через поиск, либо в списке.
   
### Ожидаемый результат:
Созданная задача найдена с помощью поиска.

### Фактический результат:  
Созданная задача не найдена ни с помощью поиска, ни просто в списке.
