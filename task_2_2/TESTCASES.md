## Тест 1. Пользователь создаёт задачу.  

### Шаги:
1. Сформировать случайное имя задачи.
2. Перейти на страницу https://avito-tech-internship-psi.vercel.app/  
3. Открыть окно создания задачи.
4. Заполнить все обязательные и небязательные поля, выбрать 1-ый вариант во всех активных выпадающих списках, создать задачу.
5. Найти созданную задачу по имени через поиск.   

### Ожидаемый результат:
Созданная задача найдена с помощью поиска.

## Тест 2. Открытие карточки задачи.

### Шаги:
Авторизоваться под пользователем с эковкладом 
1. Перейти на страницу https://avito-tech-internship-psi.vercel.app/
2. Открыть первую задачу в списке задач.
3. Проверить, открыта ли карточка задачи.

### Ожидаемый результат:
Карточка задачи найдена на странице.
